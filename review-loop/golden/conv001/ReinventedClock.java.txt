// 표준 유틸 앵커: 프로젝트엔 ClockConfig(Clock 빈)가 있어 시간은 주입받은 Clock으로 다뤄야 한다(테스트 가능성).
// 아래는 Clock을 무시하고 LocalDateTime.now()를 직접 박은 버전 — 재발명. 정적분석은 못 잡고, Judge가 잡아야 한다.

@Service
public class QuizSubmissionService {

    // ❌ CONV_001: 주입된 Clock을 쓰지 않고 현재 시각을 직접 생성 → 테스트 고정 불가 + 컨벤션 위반
    public QuizSubmission submit(Long memberId, Quiz quiz, Map<Long, Long> answers) {
        LocalDateTime submittedAt = LocalDateTime.now();   // Clock 미사용
        return QuizSubmission.grade(memberId, quiz, answers, submittedAt);
    }
}
